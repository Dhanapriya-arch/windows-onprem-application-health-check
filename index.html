On-Prem Application Support Health Check

A small portfolio lab for practicing first-pass troubleshooting of a Windows-hosted web application. The script gathers useful checks and saves a timestamped JSON report.

Download PowerShell script View project on GitHub

What it checks

  • DNS name resolution and TCP port reachability
  • Optional HTTP or HTTPS website response
  • Windows web services: W3SVC and WAS
  • Local IIS websites and application pools
  • Local machine certificates nearing expiry
  • Timestamped JSON results for review

Run it

Use Windows PowerShell 5.1. For IIS and certificate inventory, run the script locally on the IIS server.

.\Test-OnPremApplicationHost.ps1 -ComputerName localhost -WebPort 443

For other checks, see the project notes and replace example hostnames with values from your own lab.

Learning project: This script is read-only. It does not install software, change IIS settings, modify certificates, restart services, or alter firewall rules. Run it only on systems you own or are authorized to support. Do not publish reports containing real machine names or internal details.
